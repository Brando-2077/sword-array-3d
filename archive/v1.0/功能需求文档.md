# 大庚剑阵 · 灵动篇 — 产品功能需求文档

> 版本：v1.0 | 日期：2026-06-23 | 用途：功能修改的基准文档，改功能请基于本文档，勿随意改动无关代码。

---

## 一、产品概述

**大庚剑阵 · 灵动篇** 是一款基于手势识别的沉浸式 3D 飞剑操控体验。

- 通过摄像头捕捉双手动作，实时操控多把飞剑在虚空中结成剑阵
- 题材来源：《凡人修仙传》韩立 · 大庚剑阵
- 技术架构：React 19 + TypeScript + Vite 6 + Three.js + MediaPipe Hands + GLSL Shader
- 部署方式：静态站点，CDN 加载 MediaPipe，无需后端

## 二、手势控制规范（最终正确版）

> ⚠️ 历史遗留错误较多，以下为最终确认版本，修改代码时以此为准。

### 2.1 左右手分工


| 手      | 控制参数  | 数据来源                 | 说明                                      |
| ------ | ----- | -------------------- | --------------------------------------- |
| **左手** | 飞剑数量  | `left.fingerCount`   | 1~5 指 → 8/16/32/64/128（见 2.3）           |
| **左手** | 剑光速度  | `left.distance`      | 距离越远→速度越快，5 档（见 2.4）                    |
| **左手** | 锁定/解锁 | `left.isFist`        | 握拳=锁定当前所有左手控制的参数，同步在UI面板上锁定显示状态，松开=恢复实时 |
| **右手** | 剑阵招式  | `right.fingerCount`  | 1~5 指 + 握拳，共6 种（见 2.2）                  |
| **右手** | 剑体大小  | `right.distance`     | 距离越近→剑越大（5~30），见 2.5                    |
| **右手** | 光标定位  | `right.x`, `right.y` | 剑群整体跟随右手位置移动                            |


### 2.2 右手手势 → 剑阵招式映射


| 右手手势        | `right.fingerCount` | 剑阵名称      | 代码枚举           | 说明                                                                                                                 |
| ----------- | ------------------- | --------- | -------------- | ------------------------------------------------------------------------------------------------------------------ |
| 握拳          | `isFist=true`       | **剑丸归元**  | `RETRACT`      | 飞剑螺旋收敛于手部附近，形成海胆状                                                                                                  |
| 1 指伸出       | 1                   | **青元剑河**  | `POINT_STRIKE` | 飞舰舰群像一条蜿蜒的河流一样，追随手部游动                                                                                              |
| 2 指伸出       | 2                   | **巨剑术**   | `DUAL_STREAM`  | 所有剑逐渐聚拢，融合成一把，变得越来越大,巨型宽厚青金交织光剑，剑身布满流动金属光泽纹路，剑身两侧溢出厚重青绿色光雾，边缘向外飘散金属碎粒，体积庞大厚重，                                      |
| 3 指伸出       | 3                   | **剑影分光术** | `TRIPLE_HELIX` | 1道实色主剑光搭配3道半透明浅青剑影，错落分层排布，每道剑光自带短残影粒子，虚实层次分明，多道剑光呈扇形平铺陈列。                                                          |
| 4 指伸出       | 4                   | **庚金盾幕**  | `FAN_WAVE`     | 由剑组成的三层同心圆，由内而外剑的数量增多，剑尖朝外，每一层用相反的速度和方向旋转                                                                          |
| 5 指伸出（摊掌全伸） | 5                   | **大庚剑阵**  | `SWARM`        | 圆形庚金法阵基底纹路发光，场内密布千百根细如发丝的青白剑丝，无序交织缠绕形成绞杀光网，整片区域布满细碎切割光点。大面积嫩绿色光阵，柔和流线型剑光循环交织，空中漂浮嫩芽、花瓣粒子，法阵边缘缠绕动态青色藤蔓微光，光效温润无锋利锐边。 |


> **无手势时**（双手离开摄像头视野）：进入 **剑意感知（IDLE）** 状态，飞剑在屏幕附近自由穿梭，不消失。

### 2.3 左手手指 → 飞剑数量映射


| 左手伸出手指数  | 飞剑数量           | 防抖要求           |
| -------- | -------------- | -------------- |
| 1 指      | 8              | 手势稳定 300ms 后生效 |
| 2 指      | 16             | 手势稳定 300ms 后生效 |
| 3 指      | 32             | 手势稳定 300ms 后生效 |
| 4 指      | 64             | 手势稳定 300ms 后生效 |
| 5 指      | 128            | 手势稳定 300ms 后生效 |
| 握拳 / 0 指 | 不改变数量（由锁定逻辑处理） | —              |


- 防抖逻辑：`pendingRef.count` 记录目标值，`lastChangeTime` 记录最后一次变化时间，稳定 300ms 后才写入 `stableRef.count`
- 生效时机：仅在 `!locked && left.detected && left.fingerCount >= 1 && left.fingerCount <= 5` 时计算

### 2.4 左手距离 → 剑光速度映射

`left.distance` 范围 0~1（MediaPipe 自适应标定，以手部大小为参照）。


| `distance` 分档 | 档位标签 | 速度系数 `animSpeed` |
| ------------- | ---- | ---------------- |
| 0.00 ~ 0.125  | 极缓   | 0.25             |
| 0.125 ~ 0.375 | 缓流   | 0.50             |
| 0.375 ~ 0.625 | 中速   | 0.75             |
| 0.625 ~ 0.875 | 疾驰   | 1.00             |
| 0.875 ~ 1.0   | 雷光   | 1.75             |


- 实时跟随，无防抖
- UI 显示：`speedLevel = Math.round(left.distance * 4)`，对应 0~4 五档

### 2.5 右手距离 → 剑体大小映射

`right.distance` 范围 0~1。

- **计算公式**：`swordScale = 5 + right.distance * 25`（范围 5~30）
- **透视效果**：`swordScale` 越大 → 剑群 Z 坐标越靠近摄像头（`moveT.z += (swordScale - 5) * 18`，范围 0~450）
- 实时跟随，无防抖
- UI 显示：`scalePct = ((swordScale - 5) / 25) * 100`（百分比进度条）

### 2.6 锁定逻辑

- **触发**：左手握拳（`left.isFist === true`）
- **效果**：冻结 `swordScale`、`swordCount`、`animSpeed` 三个参数，不再随手势变化
- **解除**：左手打开（非握拳状态），恢复实时跟随
- **实现**：`lockedRef.current.locked = true`，HandTracker 输出 `locked: true`，SwordArray3D 收到后跳过参数更新

## 三、剑阵视觉效果设计

### 3.1 总体视觉规范


| 项目       | 要求                                                    | 备注              |
| -------- | ----------------------------------------------------- | --------------- |
| 基色       | **绿色系**（翠绿/青绿/墨绿/碧绿）                                  | 每种阵式有所区别        |
| 光效点缀色    | **金色**（`rgb(255, 219, 102)` = `vec3(1.0, 0.85, 0.4)`） | 剑尖、护手环、能量脉冲用金色  |
| 整体亮度     | **偏低**                                                | 不要过亮，光晕柔和       |
| Bloom 强度 | `strength = 0.6`（动态脉冲 ±25%）                           | UnrealBloomPass |
| 剑身材质     | 自定义 GLSL Shader                                       | 详见 3.2          |


### 3.2 Shader 设计规范（`swordFragmentShader`）

**颜色函数 `palette(formation, t)`**：


| formation 值 | 对应阵式                    | 颜色（暗端 → 亮端）                                    |
| ----------- | ----------------------- | ---------------------------------------------- |
| < 1.5       | IDLE（剑意感知）              | `vec3(0,0.3,0.12)` → `vec3(0.15,0.65,0.3)`     |
| < 2.5       | POINT_STRIKE（**青元剑河**）  | `vec3(0,0.35,0.15)` → `vec3(0.2,0.7,0.25)`     |
| < 3.5       | DUAL_STREAM（**巨剑术**）    | `vec3(0,0.4,0.2)` → `vec3(0.15,0.65,0.35)`     |
| < 4.5       | TRIPLE_HELIX（**剑影分光术**） | `vec3(0.05,0.25,0.1)` → `vec3(0.2,0.55,0.2)`   |
| < 5.5       | FAN_WAVE（**庚金盾幕**）      | `vec3(0.1,0.4,0.2)` → `vec3(0.35,0.7,0.4)`     |
| < 6.5       | SWARM（**大庚剑阵**）         | `vec3(0.05,0.35,0.15)` → `vec3(0.25,0.65,0.3)` |
| ≥ 7.5       | RETRACT（剑丸归元）           | `vec3(0.02,0.15,0.05)` → `vec3(0.1,0.4,0.15)`  |


**金色光效（`gold = vec3(1.0, 0.85, 0.4)`）**：


| 位置               | 效果                                            | 亮度系数    |
| ---------------- | --------------------------------------------- | ------- |
| 剑刃（`isBlade`）    | 能量脉冲：`sin(time*4 + height*0.8) * gold * 0.12` | 低（0.12） |
| 剑尖（`isTip`）      | 金色剑尖光：`sin(time*12) * gold * 0.3`             | 中（0.3）  |
| 护手环（`guardRing`） | 金色护手环高光：`gold * 0.25`                         | 低（0.25） |
| 边缘（菲涅尔）          | 金色边缘光：`gold * vFresnel * 0.8`                 | 动态      |
| 速度光              | 金色速度光：`gold * speedGlow * 0.2`                | 动态      |


**重要**：`gold` 变量必须在 `main()` 函数内赋值（全局作用域不允许非常量初始化）。

### 3.3 七种剑阵的空间行为设计

#### ① 剑丸归元（RETRACT — 左手握拳）

- **视觉**：飞剑螺旋收敛为一个球体，围绕手部旋转
- **运动**：`orbitAngle = time*2 + offset*8`，球形轨道，`contractFactor` 控制收缩
- **特色**：握拳时球体收缩，打开时球体扩张

#### ② 青元剑河（POINT_STRIKE — 右手 1 指）

- **视觉**：飞剑排列成**中华龙**形曲线，龙头跟随手部位置
- **运动**：
  - 龙身沿手部运动方向延伸（静止时默认向右）
  - 正弦波浪：左右摆动 + 上下翻腾
  - 龙身粗细：龙头宽 → 龙尾窄
- **龙身长度**：`dragonLength = 900`
- **特色**：真正"龙形"，不是简单的曲线

#### ③ **巨剑术**（DUAL_STREAM — 右手 2 指）

- **视觉**：三条螺旋龙形轨迹缠绕运动

#### ⑤ **庚金盾幕**（FAN_WAVE — 右手 4 指）

#### ⑥ 大庚剑阵（SWARM — 右手 5 指）

## 四、飞剑物理运动规范

### 4.1 PD 控制器参数


| 参数         | 值                                  | 说明                          |
| ---------- | ---------------------------------- | --------------------------- |
| `kp`（弹簧系数） | `0.16 * animSpeed`                 | 随速度档位动态调整                   |
| 最大弹簧力      | `dist*dist*0.001 + dist*kp`，上限 260 | 防止过冲                        |
| 阻尼系数       | `0.6`                              |                             |
| 速度上限       | `180`                              | 超过则归一化到 180                 |
| 速度下限       | `15`                               | 低于此值且 >0.01 时，归一化到 15（防止卡死） |
| 速度衰减       | `0.92` / 帧                         | 每帧乘以 0.92                   |


### 4.2 有机摆动（Organic Oscillation）

- 每把剑叠加独立的正弦摆动
- 幅度：`8 + (1-frontRatio)*12`（剑尾摆动更大）
- 频率：`time*5 + offset*2.5`
- 三个轴向：X、Y、Z 各叠加不同相位的摆动

### 4.3 飞剑朝向

- **有速度时**：剑身朝向速度方向（`Quaternion.setFromUnitVectors(Y, velDir)`）
- **静止时**：剑身朝向 `-Z` 方向（默认朝向屏幕内）

### 4.4 飞剑大小（Instance Scale）

- **计算公式**：`scale = vec3(swordScale, swordScale, swordScale)`
- **透视效果**：`swordScale` 越大 → `moveT.z` 越靠近摄像头（见 2.5）
- **范围**：5~~30（右手距离 0~~1 映射）

## 六、MediaPipe 手势识别规范

### 6.1 手指计数算法（`fingersUp`）

**输入**：MediaPipe 21 个手部关键点

**算法**：

1. 计算手腕（landmark[0]）到指尖/指根的距离
2. 指尖距离 > 指根距离 × 1.15 → 判定为"伸出"
3. 返回：`count`（伸出手指数）、`allUp`（≥5 指伸出）、`noneUp`（≤1 指伸出）

**注意**：原逻辑（用指尖/手腕距离比）不准确，已改为指尖/指根距离比。

### 6.2 左右手分类

**优先级**：

1. 优先使用 `res.multiHandedness[i].label`（MediaPipe 返回的左右手标签）
2. 降级：计算手部关键点平均 X 坐标，`avgX < 0.5` → 右手（镜像摄像头中右手出现在左侧）

### 6.3 坐标镜像

**问题**：MediaPipe 返回的是非镜像坐标，但摄像头画面是镜像的（用户看到的是镜像）

**修复**：`right.x = 1 - rightHand[9].x`（手心中心 X 坐标取反）

### 6.4 自适应距离标定（`DistanceCalibrator`）

**问题**：不同用户的手大小不同，固定距离阈值不准确

**解决方案**：

1. 前 60 帧（~2 秒）：采集手部大小基准值（`refSize`）
2. 之后：实时手部大小 / 基准值 → `ratio`，映射到 0~1

**计算公式**：

```typescript
ratio = handSize / refSize;
distance = clamp((ratio - 0.4) / 1.6, 0, 1);
```

### 6.5 防失控机制

**问题**：MediaPipe 并发调用 `hands.send()` 导致崩溃

**解决方案**：

- 添加 `sending` 标志位
- `sending === true` 时跳过本次 `hands.send()`
